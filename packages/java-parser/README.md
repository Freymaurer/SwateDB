# @swatedb/java-parser

Java OWL/OBO parser package.

Status: Phase 0 scaffold only.

## Planned Responsibilities

- Parse .owl and .obo files.
- Expose a stable parser entrypoint for TypeScript bridge usage.
- Produce a shaded JAR for runtime usage.

## Current Commands

```bash
npm run lint
npm run build
npm run test
```

These are placeholders until Phase 1 introduces Maven build and tests.
