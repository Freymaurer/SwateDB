# @swatedb/backend

Backend microservice package for ingestion, indexing, and MOD-API delivery.

Status: Phase 0 scaffold only.

## Planned Responsibilities

- Expose health, admin, webhook, and MOD-API routes.
- Manage Neo4j schema and ontology import operations.
- Coordinate background import jobs.

## Current Commands

```bash
npm run lint
npm run build
npm run test
```
